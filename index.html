JS UI Lab

Interactive UI components built with vanilla JavaScript — no frameworks or libraries. Each one is accessible, keyboard-friendly and ready to reuse.

Components

Accordion

A list of headings that show or hide their content. Useful for FAQs and long pages where not everything needs to be visible at once.

Demo

The demo is coming soon.

What it does

  • Opens and closes sections on click
  • Works from the keyboard: Tab, Enter and Space
  • Tells screen readers whether a section is open or closed
  • Several accordions on one page work independently

Modal

A dialog that opens on top of the page and asks for the user's attention. Useful for confirmations, short forms and details.

Demo

The demo is coming soon.

What it does

  • Opens from a button and returns focus to it when closed
  • Closes with Escape, the close button or a click outside
  • Keeps keyboard focus inside while open
  • Hides the page behind it from screen readers
